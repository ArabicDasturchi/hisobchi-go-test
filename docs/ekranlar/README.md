# Demo ekranlar (oldin / keyin)

Soxta demo ma'lumot bilan, telefon (390 px) va kompyuter (1366 px) ko'rinishida. Haqiqiy mijoz, telefon raqami va qarz yo'q.

- `*-oldin.png`: `main` holati (PANEL-1/2 PR'larisiz), kengaytirilgan demo ma'lumot bilan.
- `*-keyin.png`: PANEL-1/2 PR'lari (#19 Yangi savdo, #20 Bosh sahifa, #21 Ta'minotchi va kirim, #22 Birliklar) birlashtirilgan holat. Bu yig'ma faqat lokalda sinov uchun yig'ilgan, `main` ga yozilmagan.

Qayta olish:

```bash
npm run screenshots -- oldin    # yoki: keyin (Chrome/Edge o'rnatilgan bo'lishi kerak; brauzer yuklab olinmaydi)
```
