# Demo ekranlar (oldin / keyin)

Soxta demo ma'lumot bilan, telefon (390 px) va kompyuter (1366 px) ko'rinishida. Haqiqiy mijoz, telefon raqami va qarz yo'q.

- `*-oldin.png`: `main` holati (MENYU-DAFTAR PR'larisiz). `mijoz-daftari`, `taminotchi-daftari` va `hisobot` oldin holatida yo'q yoki eski ko'rinishda.
- `*-keyin.png`: MENYU-DAFTAR M1–M5 PR'lari (#24–#28) birlashtirilgan holat. Bu yig'ma faqat lokalda skrinshot uchun yig'ilgan, `main` ga yozilmagan.
- `kirim-daftari-*-oldin.png` — eski Kirim daftari (endi `ombor-kirim-*-keyin.png`).

Qayta olish:

```bash
npm run screenshots -- oldin    # yoki: keyin (Chrome/Edge o'rnatilgan bo'lishi kerak; brauzer yuklab olinmaydi)
```
